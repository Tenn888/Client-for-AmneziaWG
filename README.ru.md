# 🔐 Client for AmneziaWG

Современный графический клиент для **AmneziaWG**, разработанный на **Python** и **PyQt6** для **Arch Linux** и **KDE Plasma**.

Приложение предоставляет удобный графический интерфейс для управления VPN-конфигурациями AmneziaWG, поддерживает автоматический запуск и интеграцию с системным треем KDE.

---

## ✨ Возможности

- 🖥️ Современный графический интерфейс на PyQt6
- 🔐 Подключение и отключение VPN AmneziaWG
- 📂 Импорт VPN-конфигураций в формате `.conf` и `.zip`
- 📋 Автоматическое обнаружение установленных VPN-профилей
- 🟢 Интеграция с системным треем KDE Plasma
- 🚀 Автоматический запуск при входе в систему
- ⚡ Быстрое переключение VPN через меню в трее
- 🔒 Автоматическая настройка `sudoers` для управления VPN без ввода пароля

---

## 📋 Требования

- Arch Linux
- KDE Plasma 6
- Python 3
- PyQt6

Скрипт установки автоматически устанавливает необходимые пакеты:

- `yay` (если отсутствует)
- `amneziawg-dkms`
- `amneziawg-tools`
- `amneziawg-go`
- `unzip`

# 🚀 Установка

Поместите следующие файлы **в одну директорию**:

```text
amneziawg-client
amneziawg-client.desktop
install.sh
uninstall.sh
service.sh
```

Сделайте скрипты исполняемыми:

```bash
chmod +x service.sh install.sh uninstall.sh
```

Запустите менеджер приложения:

```bash
./service.sh
```

В открывшемся меню выберите пункт **«Установить приложение»**.

Во время установки автоматически:

- устанавливаются необходимые зависимости;
- устанавливается AmneziaWG;
- создаётся каталог `/etc/amnezia/amneziawg`;
- настраиваются правила `sudoers`;
- приложение копируется в `/opt/amneziawg-client`;
- устанавливается desktop-файл;
- включается автозапуск для текущего пользователя.

## Сборка

При необходимости установите PyInstaller:

```bash
pip install pyinstaller
```

Клонируйте репозиторий:

```bash
git clone https://github.com/Tenn888/Client-for-AmneziaWG.git
cd Client-for-AmneziaWG
```

Соберите исполняемый файл:

```bash
pyinstaller \
    --onefile \
    --windowed \
    --name amneziawg-client \
    --add-data "Images:Images" \
    --hidden-import=PyQt6 \
    main.py
```

После сборки исполняемый файл будет находиться в:

```text
dist/amneziawg-client
```

# ▶️ Использование

Обычный запуск:

```bash
/opt/amneziawg-client/amneziawg-client
```

Запуск в свернутом виде (в системный трей):

```bash
/opt/amneziawg-client/amneziawg-client --minimized
```

---

# 🖱️ Системный трей

### Левый клик

- Показать или скрыть главное окно.

### Правый клик

- Просмотреть доступные VPN-конфигурации.
- Подключить или отключить VPN.
- Завершить работу приложения.

---

# ⚙️ Управление приложением

В проект входит простой скрипт управления приложением.

Запуск:

```bash
./service.sh
```

Доступные действия:

```text
1) Включить автозапуск
2) Отключить автозапуск
3) Удалить приложение
0) Выход
```

---

# 🔄 Обновление

Соберите новую версию приложения и замените исполняемый файл:

```bash
sudo cp dist/amneziawg-client /opt/amneziawg-client/
```

После этого перезапустите приложение.

---

# 🗑️ Удаление

Для полного удаления приложения:

```bash
./service.sh
```

или

```bash
sudo ./uninstall.sh
```

Будут удалены:

- файлы приложения;
- desktop-файл;
- настройки автозапуска;
- конфигурация `sudoers`.
